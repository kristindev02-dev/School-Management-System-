School Management System Documentation

This page explains the three main files in the project: app.py, templates/base.html, and templates/students.html.

1. app.py

app.py is the Python program that runs the web server and talks to the database.

What it does

  • Creates the Flask application.
  • Connects to the MySQL database using a connection pool.
  • Defines routes for the website pages.
  • Handles adding, updating, deleting, and showing student records.

Key parts

Imports:

import mysql.connector from mysql.connector import pooling from flask import Flask, redirect, render_template, request, url_for

This loads the tools needed for database connections and Flask web handling.

Creating the app:

app = Flask(__name__, template_folder='templates', static_folder='static')

This tells Flask where the HTML templates and static files (like CSS) are located.

Database pool:

db_pool = pooling.MySQLConnectionPool(...)

The connection pool keeps database connections ready so the app can handle requests smoothly.

Routes:

  • @app.route('/') — home route, sends users to the student page.
  • @app.get('/students') — loads the student list and the form page.
  • @app.post('/students') — saves a new student when the form is submitted.
  • @app.post('/students/<int:student_id>/update') — updates an existing student.
  • @app.post('/students/<int:student_id>/delete') — deletes a student.

Each route uses a function to do work, then returns either a page or a redirect back to the student page.

2. templates/base.html

base.html is the general page layout used by other pages. It contains the page header, sidebar, and the layout structure.

Key parts

Template inheritance:

{% block content %}{% endblock %}

This is a placeholder. Other pages place their own content here.

CSS link:

<link rel="stylesheet" href="{{ url_for('static', filename='style.css') }}">

This loads the stylesheet from the static folder.

Navigation links:

<a href="{{ url_for('students') }}">Students</a>

These links use Flask's url_for function so the app generates the correct page address.

3. templates/students.html

students.html is the page where users add, edit, and see student information.

How it works

The page extends base.html and fills the content block with a student form and a table.

Important features

  • Form mode: The page can show either "Add Student" or "Update Student" depending on whether edit_student exists.
  • Form fields: Name, age, email, phone, and address are sent to the server when the form is submitted.
  • Student table: Displays all students from the database.
  • Edit link: Uses ?edit_id=... to fill the form with existing student data.
  • Delete button: Sends a request to remove the student from the database.

Key template syntax

{{ student.name }} prints a value from Python into the HTML.

{% if edit_student %} is a conditional statement that chooses between add and update mode.

{% for student in students %} loops through all student records and creates one table row per student.

How the files work together

The flow is:

  1. User opens the app in a browser.
  2. Flask runs app.py, and the request goes to /students.
  3. app.py fetches student data from the database.
  4. students.html shows the student list and form inside the layout from base.html.
  5. If the user submits the form, app.py saves the data and redirects back to /students.
Tip: You can open this file in a browser to read it like a regular webpage.
